VERSIÓN 7.2 · EL SALVADOR

📘 Introducción al Sistema

El Sistema ERP Integral ITCPO es una solución tecnológica integral diseñada para centralizar la gestión administrativa, financiera, fiscal y operativa de empresas y profesionales independientes en El Salvador.

Funciona 100% local en el navegador. Incluye soporte nativo para Documentos Tributarios Electrónicos (DTE), catálogo de cuentas contables completo, sincronización automática entre operaciones y pólizas contables, y un centro de análisis avanzado con reportes financieros, de inventarios, clientes y proveedores.

💡 Versión 7.2: Nueva funcionalidad de corrección de tipo de DTE (venta ↔ compra) con actualización automática de todo el sistema: facturas, pólizas contables, contactos, reportes y libros de IVA. (versión para fines didácticos)
🔄 Corrección de Tipo de DTE

🔄 Cambiar el tipo de un DTE (Venta ↔ Compra)

Si un DTE fue clasificado incorrectamente durante la importación (por ejemplo, se detectó como venta cuando debía ser compra), puede corregirlo fácilmente:

  1. Vaya al módulo 🧾 DTE Importados
  2. Localice el DTE que desea corregir en la tabla
  3. Haga clic en el botón 🔄 Cambiar tipo
  4. Revise el resumen del cambio propuesto (tipo actual → nuevo tipo)
  5. Confirme el cambio

¿Qué se actualiza automáticamente?

  • Factura: se mueve de ventas a compras (o viceversa) con nuevo folio de la serie correspondiente
  • Rol emisor/receptor: se invierte la perspectiva (si era venta, el usuario pasa de emisor a receptor)
  • Contacto: el cliente se convierte en proveedor (o viceversa)
  • Póliza contable: se elimina la póliza antigua y se genera una nueva con las cuentas correctas:
    • Si es venta: Cargo 1103/1102.01 / Abono 4201 / Abono 2102
    • Si es compra: Cargo 6115 / Cargo 1104 / Abono 2101/1102.01
  • Reportes: libros de IVA, ventas/compras mensuales, balance general, estado de resultados, flujo de caja
  • Notificaciones: se regeneran las alertas de vencimiento
⚠️ Importante: El UUID, número de control, montos e IVA del DTE se mantienen intactos. Solo cambia la perspectiva contable (venta ↔ compra).
💾 Gestión de Datos

🗑️ Eliminar todos los datos

El módulo de 💾 Respaldos incluye una Zona Peligrosa con la opción de eliminar todos los datos operativos del sistema, conservando únicamente el catálogo de cuentas contables y la configuración.

⚠️ Importante: Antes de eliminar los datos, se recomienda hacer un respaldo completo mediante el botón "📥 Hacer respaldo primero".
